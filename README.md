# ARC Website

ARC is a productivity website concept made for CS146 in Fall 2026. It is designed around task groups for work, fitness, finances, learning, personal goals, relationships, projects, custom tasks and diet planning.

This deliverable is a responsive HTML and CSS website. It presents the proposed app; account creation, data storage, calendar syncing and time tracking are not implemented.

## Pages

- `index.html` — Home page and overview
- `features.html` — The nine planned task groups
- `getstarted.html` — How ARC would work
- `about.html` — Purpose and project background
- `css/styles.css` — Shared page styles, including tablet and phone layouts
- `images/` — ARC logo and background artwork

## Viewing the website

Open `index.html` in a browser. Use the navigation to visit the other pages. The entire website works without JavaScript or a backend.
